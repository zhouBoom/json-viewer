## 测试覆盖的功能

### 核心功能
1. **房源展示**: 验证首页显示6个房源卡片

4. **图片轮播**: 测试缩略图切换功能

2. **响应式**: 测试移动端视口下的显示
3. **交互效果**: 测试悬停动画效果
4. **表单交互**: 测试搜索框输入和清空

### 数据验证

## 运行测试

### 运行所有测试
```bash
npm test
```

### 运行测试并查看 UI
```bash
npm run test:ui
```

### 查看测试报告
```bash
npm run test:report
```

## 测试配置

测试配置文件: `playwright.config.js`

- **基础 URL**: http://localhost:5173
- **测试超时**: 30秒
- **重试次数**: CI 环境 2次，本地 0次
- **并行执行**: 是
- **报告格式**: HTML

## 注意事项

1. 测试会自动启动开发服务器
2. 确保端口 5173 未被占用
3. 首次运行需要安装 Playwright 浏览器: `npx playwright install chromium`
4. 测试结果会生成 HTML 报告在 `playwright-report` 目录

## 测试最佳实践

本测试套件遵循以下最佳实践:

1. **清晰的测试描述**: 每个测试都有明确的中文描述
2. **独立性**: 每个测试独立运行，不依赖其他测试
3. **等待策略**: 使用适当的等待确保元素加载
4. **断言明确**: 使用清晰的断言验证预期行为
5. **错误处理**: 对话框和异步操作有适当的处理
