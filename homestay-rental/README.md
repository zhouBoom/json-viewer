# 悦居民宿 - 民宿租房前端项目

一个基于 Vue 3 + Vite 开发的现代化民宿租房平台前端应用。

## ✨ 功能特性

- 🏠 **房源展示** - 精美的房源卡片网格展示
- 🔍 **智能搜索** - 实时搜索房源，支持关键词匹配
- 🎯 **高级筛选** - 按价格范围、房型等条件筛选
- 📱 **响应式设计** - 完美适配 PC 和移动端
- 🎨 **现代化 UI** - 渐变背景、圆角卡片、流畅动画
- 📸 **图片轮播** - 房源详情页支持多图展示
- ⭐ **用户评价** - 展示真实用户评价和评分
- 👤 **房东信息** - 详细的房东介绍和联系方式

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

项目将在 `http://localhost:5173` 启动

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 🌐 页面说明

### 首页 (/)
- 展示所有房源的卡片网格
- 顶部搜索栏支持实时搜索
- 点击房源卡片进入详情页

### 房源详情页 (/room/:id)
- 房源图片轮播展示
- 详细的房源信息（卧室、床位、卫生间等）
- 房东个人信息和介绍
- 完整的设施配备列表
- 用户评价和评分
- 预订功能（演示）

### 搜索页 (/search)
- 左侧筛选面板（价格、房型）
- 实时搜索和筛选
- 显示匹配的房源数量

## 📱 响应式设计

项目完全支持响应式布局：
- **桌面端**: 1200px+ 最佳体验
- **平板端**: 768px - 1200px 自适应布局
- **移动端**: < 768px 单列布局

## 🛠️ 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **路由**: Vue Router 4
- **样式**: 原生 CSS
- **字体**: Google Fonts (Inter)

## 📝 数据说明

项目使用模拟数据 (`src/data/rooms.js`)，包含 6 个精心设计的房源示例，每个房源包含：
- 基本信息（标题、描述、价格、位置）
- 房源规格（卧室、床位、卫生间、最大入住人数）
- 房东信息
- 设施配备列表
- 用户评价
